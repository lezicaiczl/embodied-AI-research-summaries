# CR-VLA

**论文标题：** *CR-VLA: Compression-Robust Vision-Language-Action Models for Remote Deployment*

## 研究问题

远程机器人操作受网络带宽限制时，系统通常压缩视觉输入以满足传输和推理频率要求。压缩会损伤视觉信息，进而影响场景理解和动作生成。

## 方法概览

- **Compression Prior Extraction（CPE）**：使用在 DROID 数据上后训练的 VAE 风格编码器，从主相机和腕部相机的压缩图像中提取紧凑压缩先验。
- **Compression-Aware Modulation（CAM）**：通过跨注意力将压缩先验与视觉 token 融合，恢复压缩受损的视觉表征；训练期间还用重建头对齐压缩输入与干净输入的中间特征，推理时移除该辅助头。
- **Compression-Prior Action Anchoring（CPAA）**：把压缩先验直接注入动作专家的注意力模块，作为动作锚点，帮助控制策略在视觉质量变化时保持稳定。
- **渐进式对齐训练**：先训练 CPE 与 CAM，再联合训练 LoRA、动作头和重建头，并逐步增加压缩输入比例。

## 实验设置与结果

论文在 LIBERO 四个任务套件和 CALVIN ABC→D 长时序任务上评估模型，覆盖干净图像、四档固定带宽和波动带宽。带宽以 bits per pixel per frame（BPP）计，固定压缩设置为 0.50、0.40、0.32 和 0.25 BPP。CR-VLA 在压缩条件下总体优于基线，尤其在长时序操作任务上保持更高的成功率；在 CALVIN 波动带宽实验中，五步任务成功率为 56.9%，平均完成长度为 3.758。论文报告适配方法训练 45K 次迭代，少于直接使用的 200K 迭代基线检查点。

真实机器人实验使用 AgileX 单臂平台，并采用机器人端采集与编码、远端 GPU 推理的部署方式。链路带宽通过网络网关进行数据包级限制，测试包含固定高带宽和波动带宽场景。每个任务使用 50 条示范训练，并以每项 20 次试验评估；论文报告 CR-VLA 在波动带宽下改善多项操作任务成功率，P95 闭环延迟比基线增加约 9 ms。

消融实验分别移除 CPE、CAM、动作锚点和重建头后，长时序任务表现均有下降，支持这些组件对压缩鲁棒性和动作稳定性的作用。
