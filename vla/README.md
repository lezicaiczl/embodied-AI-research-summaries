# 视觉语言动作（VLA）

面向远程机器人操作中的网络带宽约束，提升压缩视觉输入下的场景理解与动作生成稳定性。

## 已有成果

PPT 中的机械臂端到端操作演示以自然语言任务为输入，示例包括打开抽屉并把茄子放到上方第一层平台、把香蕉放进白色盘子，以及把杯子放入碗中后将其整体放到盘子上。实验室具备部署开源 VLA 模型并针对具体任务微调的能力。

### 低带宽远程操作的压缩鲁棒建模

- 提取图像压缩退化先验，并将先验与视觉 token 对齐。
- 通过压缩感知调制恢复受损视觉表征，并使用辅助重建监督减少中间特征偏移。
- 将压缩先验直接注入动作专家，作为动作锚点，稳定不同压缩等级下的控制输出。
- 采用渐进式训练流程，在视觉恢复基础上逐步引入压缩输入与动作适配。

### 仿真与实机验证

在 LIBERO 和 CALVIN 长时序任务中评估多档固定与波动带宽；并在 AgileX 单臂平台上通过真实受限网络链路开展远程操作测试。现有材料报告在 CALVIN 波动带宽条件下五步任务成功率为 56.9%，平均完成长度为 3.758；实机评估覆盖四类操作任务。

算法框架、仿真和实机结果见[低带宽远程操作成果](bandwidth-robust-control.md)。
